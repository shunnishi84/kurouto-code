# フロントエンド

## 概要

Amazon S3 の静的ウェブサイトホスティングで配信される UI 層です。  
Claude Code のターミナル風デザインを模しており、Amazon CloudFront 経由で HTTPS 配信されます。

## 技術スタック

| 技術 | 用途 |
|---|---|
| HTML5 | ページ構造 |
| CSS3（カスタムプロパティ） | テーマ切替（ダーク / ライト）、レイアウト |
| Vanilla JavaScript (ES2020) | API 通信・タイプライターアニメーション・スピナー |
| Amazon S3 | 静的ファイルホスティング |
| Amazon CloudFront | CDN・HTTPS 終端 |

## ファイル構成

```
frontend/
├── index.html       # エントリーポイント（HTML構造のみ）
├── css/
│   └── style.css    # 全スタイル（CSS変数によるテーマ管理）
└── js/
    └── app.js       # UI ロジック全般
```

## 主な機能

- **ターミナル風 UI** — Claude Code を模したダークテーマのチャット画面
- **ダーク / ライトモード切替** — ヘッダーのボタンで切替、`localStorage` に保存
- **タイプライター表示** — 説教テキストを一文字ずつ表示し、句読点で間を置く
- **思考中スピナー** — ブレイルスピナーと「ふむ...」などのメッセージをアニメーション表示
- **怒りメッセージ** — 3〜5 回のやり取り後にランダムで大きな怒りメッセージを表示
- **コードブロック表示** — C 言語コードを `<pre>` タグで整形表示
- **モバイル対応** — レスポンシブデザイン

## API 通信仕様

`js/app.js` の先頭に定義された `API_URL` に対して POST リクエストを送信します。

**リクエスト**
```json
{ "prompt": "ユーザー入力テキスト", "exchange_count": 3 }
```

**レスポンス**
```json
{ "rant": "説教テキスト", "angry": false }
```

## デプロイ

GitHub Actions（`.github/workflows/deployment.yml`）により、`main` ブランチへのプッシュ時に自動デプロイされます。
